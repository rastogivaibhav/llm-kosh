# llm-kosh Tray Icon

The Desktop App runs in the system tray (notification area on Windows/Linux, menu bar on macOS) to act as a background memory companion.

## Features
- **Window Management**: Clicking the tray icon toggles the visibility of the main window. Closing the main window hides it to the tray rather than quitting the app.
- **Daemon Control**: You can quickly Start or Stop the background daemon directly from the tray context menu.
- **Status Indicator**: The context menu displays whether the daemon is currently running or stopped.
- **Quit**: Use the "Quit" option in the tray menu to completely exit the application and stop the background daemon.
