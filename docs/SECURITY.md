# Security

The canonical security policy and threat model for `llm-kosh` is maintained in the repository root:

- [SECURITY.md](../SECURITY.md)

Cartridge export policy continues to use `LLM_KOSH_POLICY.json`. The Trust Gate and visibility rules are part of the broader security model documented in the canonical file above.

> [!WARNING]
> `CARTRIDGE_POLICY.json` is a deprecated naming convention. Use `LLM_KOSH_POLICY.json`.
