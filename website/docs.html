Documentation

llm-kosh is a local-first memory cartridge for MCP-compatible AI clients. It stores memory as plain files, exposes local retrieval through CLI and MCP, and records mutations in a tamper-evident ledger.

Quickstart

Install the base package, create the default cartridge, and verify the local runtime:

python -m pip install --upgrade llm-kosh
llm-kosh install --yes
llm-kosh status

The Memory Receipt Concept

Receipts are the safe path for bringing useful AI output back into local memory. Instead of letting a chat session directly change cartridge state, you save structured output as a MEMORY_RECEIPT, then validate and review it before absorption.

The solution is the MEMORY_RECEIPT.

When you work with an LLM, ask it to return a structured receipt of what was learned, proposed, or changed:

"At the end of our work, return a MEMORY_RECEIPT describing decisions, findings, and proposed changes."

How it works

Save the receipt to your workspace, validate it, inspect the diff, and then absorb it if it looks correct:

llm-kosh validate-receipt MEMORY_RECEIPT.md
llm-kosh review-receipt MEMORY_RECEIPT.md
llm-kosh absorb MEMORY_RECEIPT.md

Approved receipts become typed local memory and future context for search, packing, and MCP-based retrieval.

Automating with the Background Service

The sustained service watches intake and receipt folders, maintains derived indexes, and exposes a local health surface.

llm-kosh service start
llm-kosh service status
llm-kosh service stop

MCP is included in the base installation and starts read-only by default:

llm-kosh --root ./my-cartridge mcp-server
llm-kosh --root ./my-cartridge mcp-test
