Documentation

LlmKosh is a DevOps pipeline for your AI context. It treats your architectural decisions, prompts, and knowledge as source code.

The Memory Receipt Concept

A major problem with chat interfaces like ChatGPT or Claude is that once a conversation ends, the context is lost forever. You might have made 10 brilliant architectural decisions in a chat thread, but your codebase doesn't know about them.

The solution is the MEMORY_RECEIPT.

When you use LlmKosh to generate a context pack for an LLM, you also give the LLM an instruction:

"At the end of our work, you must return a MEMORY_RECEIPT detailing what we learned, what decisions we made, and what code was generated."

How it works

The LLM will generate a markdown block formatted as a receipt. You simply save this output as a file (e.g., MEMORY_RECEIPT.md) in your local LlmKosh workspace, and run the absorb command:

$ llm-kosh absorb MEMORY_RECEIPT.md

LlmKosh parses the receipt, splits it into strongly-typed local files (decisions/, notes/, projects/), and links them cryptographically using provenance hashes. Next time you pack context for the LLM, the LLM will remember exactly what it did last time!

Automating with the Daemon

Tired of manually absorbing receipts? LlmKosh comes with a background watcher.

$ llm-kosh watch

If you save any file matching MEMORY_RECEIPT*.md into your receipts/ folder, the daemon will instantly detect it, parse it into knowledge, auto-resolve any architectural corrections, and archive the raw receipt into a processed folder safely.
